[ 완료 ]

1. application.properties
   - DB 연결 (MySQL, k_evolution 데이터베이스)
   - JPA (ddl-auto=update, show-sql=true)
   - Thymeleaf (cache=false)
   - HiddenMethodFilter 활성화 (PUT/DELETE 폼 지원)
   - 토스페이먼츠 키 항목 (직접 입력 필요)

--------------------------------------------------

2. 엔티티 (src/main/java/com/kevolution/entity/)

   Member.java
   - 컬럼: memberId, email(UNIQUE), password, name, phone, address, role, createdAt, updatedAt
   - 열거형: Role { USER, ADMIN }
   - @PrePersist / @PreUpdate 자동 시간 처리

   Category.java
   - 컬럼: categoryId, name

   Product.java
   - 컬럼: productId, category(FK), name, price, stock, description, imageUrl, createdAt, updatedAt
   - 메서드: update(), decreaseStock(), increaseStock()

   Cart.java
   - 컬럼: cartId, member(FK, UNIQUE)
   - 관계: CartItem 목록 (OneToMany, CascadeAll)

   CartItem.java
   - 컬럼: cartItemId, cart(FK), product(FK), quantity
   - 메서드: updateQuantity(), getTotalPrice()

   Coupon.java
   - 컬럼: couponId, name, discountType, discountValue, minOrderAmount, expiredAt
   - 열거형: DiscountType { FIXED, PERCENT }
   - 메서드: isExpired(), calculateDiscount()

   MemberCoupon.java
   - 컬럼: memberCouponId, member(FK), coupon(FK), used(is_used), usedAt
   - 메서드: use()

   Order.java
   - 테이블명: orders (order는 SQL 예약어)
   - 컬럼: orderId, member(FK), memberCoupon(FK), receiverName, receiverPhone,
           address, totalPrice, discountAmount, finalPrice, status, createdAt
   - 열거형: Status { PENDING, PAID, CANCELLED }
   - 메서드: markAsPaid(), cancel()

   OrderItem.java
   - 컬럼: orderItemId, order(FK), product(FK), productName(스냅샷), price(스냅샷), quantity
   - 메서드: getTotalPrice()

   Payment.java
   - 컬럼: paymentId, order(FK, UNIQUE), paymentKey, method, amount, status, approvedAt
   - 열거형: Status { SUCCESS, FAIL }

   OrderItemRepository.java
   - 기본 JpaRepository CRUD

   PaymentRepository.java
   - 기본 JpaRepository CRUD
